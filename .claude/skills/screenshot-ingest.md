# Screenshot Ingest Skill

Web 版が存在せずブラウザ自動操作（weekly-ingest）で到達できないスマホ専用アプリのデータを取り込みます。ユーザーがアプリ画面のスクリーンショットを Slack のインボックスチャンネルに投稿し、このスキルが画像を読み取って数値化・記録・しきい値判定を行います。

## 前提

- 取り込み定義: `automation/screenshots/*.yaml`（`_` 始まりのファイルはテンプレートなのでスキップ）
- 判定ルール: `automation/rules.yaml`（weekly-ingest と共用。`site` にはスクショ定義の `source` を指定する）
- インボックス: Slack チャンネル `#kpi-screenshot-inbox`（プライベート）。ユーザーはここにスクショを投稿するだけでよい

## 実行フロー

1. **定義読み込み**: `automation/screenshots/*.yaml` を列挙し、`enabled: true` のものだけを対象にする
2. **スクショ収集**: インボックスチャンネルの直近 7 日分のメッセージから画像ファイルを取得する
3. **読み取り**: 画像を視覚的に読み取り、各定義の `metrics` に対応する数値を抽出する。どの定義の画像かは `app` 名・画面の特徴（`capture_hint` / `notes`）から判別する
4. **正規化**: `{source, metric, value, unit, captured_at, fetched_at}` の形に揃える。`captured_at` は投稿日時を使う
5. **ルール判定**: `automation/rules.yaml` の条件を評価する
6. **通知**: インボックスチャンネルへ返信する
   - しきい値割れ: 即アラート（source・メトリクス・現在値・しきい値・メッセージ）
   - 正常時: 全 source の週次サマリを 1 通にまとめて投稿。未提出の source があれば「未提出」として明記する
7. **記録**: 実行結果スナップショットを `.context/screenshot-ingest/<date>.json` に保存する。定義に `notion_page` がある場合は、そのページの表に 1 行追記する

## 失敗時の対応

| 状況                           | 対応                                                                    |
| ------------------------------ | ----------------------------------------------------------------------- |
| 画像から数値が読み取れない     | 該当メッセージのスレッドで、どの画面を撮り直してほしいかを具体的に依頼  |
| どの定義の画像か判別できない   | スレッドで確認を依頼し、判明したら `notes` に判別のヒントを追記する提案 |
| 有効な定義に対応する投稿がない | サマリに「未提出」として含める（エラーにはしない）                      |
| 画面レイアウトが変わった       | 定義の `capture_hint` / `notes` の修正案を提示、または Issue を起票     |

## 禁止事項

- スクショに写り込んだ口座番号・カード番号・氏名などの識別子を、ログ・スナップショット・通知にそのまま書かない。必ず `***` でマスクする
- 取り込むのは数値（metrics）のみ。画像そのものをリポジトリにコミットしない
- 読み取りに自信がない値を確定値として記録しない（スレッドで確認する）

## 週次スケジュール登録（初回のみ）

Claude Code Remote の Routine として 2 本登録する:

1. **リマインダー**（スクショ投稿依頼）
   - cron: `0 12 * * 6`（UTC 指定。JST 土曜 21:00）
   - prompt: 「#kpi-screenshot-inbox に、automation/screenshots/ で有効な各アプリのスクリーンショット投稿を依頼するメッセージを送ってください」
2. **取り込み実行**
   - cron: `30 21 * * 6`（UTC 指定。JST 日曜 06:30。週次レビュー 07:00 の前に完了させる）
   - create_new_session_on_fire: true
   - prompt: 「screenshot-ingest スキルを適用して週次取り込みを実行してください」
